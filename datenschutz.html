Hosting: GitHub Pages

Die Website wird über GitHub Pages bereitgestellt, einen Dienst der GitHub, Inc. Wenn Sie eine Seite aufrufen, übermittelt Ihr Browser technisch bedingt Zugriffsdaten an die Server von GitHub, insbesondere Ihre IP-Adresse, die aufgerufene Adresse und den Zeitpunkt. Nach Angaben von GitHub wird die IP-Adresse von Besucherinnen und Besuchern einer GitHub-Pages-Website zu Sicherheitszwecken protokolliert und gespeichert, auch wenn sie nicht bei GitHub angemeldet sind (GitHub Docs, „What is GitHub Pages?“, Abschnitt „Data collection“). Einzelheiten: GitHub General Privacy Statement.

Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO: Ich habe ein berechtigtes Interesse daran, die Website sicher und zuverlässig bereitzustellen. GitHub, Inc. hat ihren Sitz in den USA. Soweit Daten dorthin übermittelt werden, stützt sich die Übermittlung auf den Angemessenheitsbeschluss der EU-Kommission zum EU-US Data Privacy Framework, soweit der Anbieter danach zertifiziert ist, und im Übrigen auf die Standardvertragsklauseln der EU-Kommission, die der Anbieter nach eigenen Angaben verwendet.

Inhalte von anderen Servern

Einige Seiten laden Programmbibliotheken von Content-Delivery-Netzwerken (CDN). Dabei übermittelt Ihr Browser Ihre IP-Adresse an den Betreiber des jeweiligen Servers, weil dieser die Datei sonst nicht ausliefern kann. Diese Website lädt Inhalte nur von diesem Server:

  • cdn.jsdelivr.net (jsDelivr): auf Seiten mit Formeln MathJax, die Bibliothek für mathematische Formeln, mit ihren Schriften; auf interaktiven Seiten die Bibliotheken für Diagramme und Eingabefelder (d3, Observable Plot, Observable Inputs, htl, marked). Datenschutzhinweise von jsDelivr

Von anderen Servern lädt diese Website nichts. Links zu anderen Websites werden erst aufgerufen, wenn Sie sie anklicken.

Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO: Ich habe ein berechtigtes Interesse daran, Formeln und interaktive Diagramme zuverlässig darzustellen. Die Betreiber können ihren Sitz außerhalb der EU haben; für eine Übermittlung in die USA gilt das oben zu GitHub Gesagte.

Die App LiveLines (livelines.recurrentanalytics.com)

Die App LiveLines läuft auf einem eigenen Rechner, den ich selbst betreibe. Sie ist über Cloudflare erreichbar (Cloudflare, Inc., USA; DNS und ein verschlüsselter Tunnel). Wenn Sie die App aufrufen, übermittelt Ihr Browser Ihre IP-Adresse und die Anfrage an Cloudflare, das sie an meinen Rechner weiterleitet. Auf meinem Rechner werden keine Zugriffsprotokolle mit IP-Adressen geführt. Datenschutzerklärung von Cloudflare

Die App lädt außerdem:

  • Kartenkacheln von CARTO (basemaps.cartocdn.com) bei jedem Aufruf der Karte; dabei übermittelt Ihr Browser Ihre IP-Adresse an CARTO. Datenschutzerklärung von CARTO
  • Pyodide von jsDelivr (cdn.jsdelivr.net), nur wenn Sie ein Modul in Ihrem Browser ausführen.

Die App misst keine Besuche. Sie liest und schreibt dasselbe Design-Cookie wie diese Website (siehe unten). Einstellungen und Ihre eigenen Modulversionen speichert Ihr Browser lokal (localStorage); sie werden nicht an mich übertragen.

Rechtsgrundlage ist Art. 6 Abs. 1 lit. f DSGVO: Ich habe ein berechtigtes Interesse daran, die App sicher bereitzustellen und die Karte darzustellen. Für eine Übermittlung in die USA gilt das oben zu GitHub Gesagte.

Ein Cookie für das Design, keine Analyse

Wenn Sie zwischen hellem und dunklem Design wechseln, speichert diese Website Ihre Wahl in einem Cookie namens ra_theme (Inhalt: light, dark oder system; Gültigkeit ein Jahr; für recurrentanalytics.com und livelines.recurrentanalytics.com), damit die App LiveLines im selben Design erscheint. Das Cookie enthält keine Kennung und dient nicht der Analyse oder Werbung. Es ist technisch erforderlich, um die von Ihnen gewünschte Einstellung umzusetzen (§ 25 Abs. 2 Nr. 2 TDDDG); Rechtsgrundlage für die Verarbeitung ist Art. 6 Abs. 1 lit. f DSGVO. Sie können es jederzeit in Ihrem Browser löschen.

Diese Website misst keine Besuche. Einige Einstellungen, etwa helles oder dunkles Design, speichert Ihr Browser lokal (localStorage), damit sie beim nächsten Besuch erhalten bleiben; ob eine Animation in diesem Besuch schon lief, merkt er sich bis zum Schließen des Tabs (sessionStorage). Diese Angaben bleiben in Ihrem Browser und werden nicht an diese Website übertragen; Sie können sie in den Einstellungen Ihres Browsers löschen.
