Heatwaves and day-ahead prices: Germany, summers 2019 to 2025

Do electricity prices rise when Germany is hot? Seven summers of day-ahead prices against measured temperatures, with your own heatwave definition and each day compared with its month.
Published

December 12, 2025

Modified

November 24, 2026

On the 33 days that belonged to a heatwave in Germany in the summers (June to August) of 2019 to 2025 (30 °C on at least three days in a row, mean of the daily maxima of six DWD stations), the day-ahead price in peak hours was a median 13 % above a normal day of the same month. Set your own definition below and see how much of that holds.

The question

Heat raises demand for cooling, lowers the efficiency of thermal power plants and can force them to curtail when rivers get warm. Solar output, on the other hand, peaks on the same days. Which wins in the market? This page looks at the day-ahead price, the price at which electricity for the next day is traded, for the German and Luxembourg bidding zone.

Comparing each day with its month

Electricity prices move far more with fuel prices than with weather: in 2022 the gas crisis multiplied the price level. So each day is compared with the median price of the days of the same month that were not part of a heatwave. A value of 1.2 means 20 % above that month’s normal day. Sunny days with very low or negative prices sit at the bottom of the chart; values beyond its range are drawn at its edge.

viewof threshold = Inputs.range([26, 34], {value: 30, step: 0.5, label: "Threshold (°C, mean of the daily maxima of six DWD stations)"})
viewof minDays = Inputs.range([1, 5], {value: 3, step: 1, label: "At least (days in a row)"})
flagged = {
  const rows = transpose(days).map((d) => ({...d, hot: d.tmax_de >= threshold}));
  for (let i = 0; i < rows.length; ) {          // mark runs of hot days long enough
    let j = i;
    while (j < rows.length && rows[j].hot === rows[i].hot) j++;
    for (let k = i; k < j; k++) rows[k].hw = rows[i].hot && j - i >= minDays;
    i = j;
  }
  const norm = d3.rollup(rows.filter((d) => !d.hw), (v) => d3.median(v, (d) => d.price_peak),
    (d) => `${d.year}-${d.month}`);
  return rows.map((d) => ({...d, rel: d.price_peak / norm.get(`${d.year}-${d.month}`)}));
}
summer = flagged.filter((d) => d.month >= 6 && d.month <= 8 && Number.isFinite(d.rel))
hwMedian = d3.median(summer.filter((d) => d.hw), (d) => d.rel)
normalMedian = d3.median(summer.filter((d) => !d.hw), (d) => d.rel)
nHw = flagged.filter((d) => d.hw && d.month >= 6 && d.month <= 8).length
md`With your definition: **${nHw}** heatwave days in June to August. On them, peak-hour prices were a median **${((hwMedian - 1) * 100).toFixed(0)} %** above the month's normal day; on other summer days **${((normalMedian - 1) * 100).toFixed(0)} %**.`

  x: {label: "Daily maximum, mean of six cities (°C)", grid: true},
  y: {label: "Peak price relative to the month's normal day", grid: true, domain: [-0.5, 2.5], clamp: true,

What this does not tell you

  • Correlation, not cause. Heat comes with other things that move prices: high solar output, low wind, plant outages, low river levels, and the same heat in neighbouring countries. This page shows what happened, not why.
  • A rough national temperature. Six stations stand in for Germany; regional heat is not resolved. Stuttgart-Echterdingen has no daily maximum from 3 July to 18 September 2023; on those days the mean is of the other five.
  • Peak hours only. The comparison uses 08:00 to 20:00 local time. Evening prices, when solar fades, behave differently.
  • Seven summers. That is few. One crisis year can shape the picture, which is why each summer is shown on its own.

Data and code

  • Day-ahead prices for the bidding zone Germany/Luxembourg, hourly, from 01 Oct 2018 to 31 Dec 2025: Bundesnetzagentur | SMARD.de (smard.de), CC BY 4.0; changed here: hourly prices averaged to a daily mean and a peak mean (08:00 to 20:00 local time). The Bundesnetzagentur is reviewing the licensing of wholesale prices; this page will follow its outcome.

import numpy as np
import pandas as pd


def ojs_data(**kwargs) -> None:
    """Hand data to the OJS cells, as Quarto's ojs_define does, but as plain text output.

    ojs_define shows an HTML output, and any HTML output makes Quarto add require.js and
    jQuery to the page; require.js then clashes with the page's other scripts
    ("Mismatched anonymous define() module"). Same JSON, written as a raw HTML block.
    """
    import json

    def convert(v):
        if isinstance(v, pd.Series):
            v = pd.DataFrame(v)
        if isinstance(v, pd.DataFrame):
            j = json.loads(v.T.to_json(orient="split"))
            return dict(zip(j["index"], j["data"]))
        return v

    v = dict(contents=[dict(name=k, value=convert(x)) for k, x in kwargs.items()])
    print('```{=html}\n<script type="ojs-define">' + json.dumps(v) + "</script>\n```")


daily = pd.read_csv("data/processed/dwd_daily.csv.gz", parse_dates=["date"])
prices = pd.read_csv("data/processed/smard_dayahead_de_lu.csv.gz", parse_dates=["datetime_utc"])

# Germany's temperature, approximated by the mean daily maximum of six large cities.
temp = (daily[daily["date"] >= "2018-10-01"].groupby("date")
        .agg(tmax_de=("tmax_c", "mean"), n_st=("tmax_c", "count")).reset_index())
temp = temp[temp["n_st"] >= 5]

# Peak hours 08:00 to 20:00 local time, as day mean.
p = prices.copy()
p["local"] = p["datetime_utc"].dt.tz_convert("Europe/Berlin")
p["date"] = p["local"].dt.tz_localize(None).dt.normalize()
p["peak"] = p["local"].dt.hour.between(8, 19)
day = p.groupby("date").agg(price_mean=("price_eur_mwh", "mean")).join(
    p[p["peak"]].groupby("date").agg(price_peak=("price_eur_mwh", "mean"))).reset_index()

df = day.merge(temp, on="date").dropna(subset=["price_peak", "tmax_de"])
df["year"] = df["date"].dt.year
df["month"] = df["date"].dt.month
span_from, span_to = df["date"].min(), df["date"].max()


def flag(d: pd.DataFrame, threshold: float = 30.0, min_days: int = 3) -> pd.Series:
    """Heatwave day: mean of the daily maxima of six DWD stations >= threshold, in a run of >= min_days such days."""
    hot = d["tmax_de"] >= threshold
    run = (hot != hot.shift()).cumsum()
    return hot & (hot.groupby(run).transform("size") >= min_days)


df = df.sort_values("date").reset_index(drop=True)
df["hw"] = flag(df)
norm = df[~df["hw"]].groupby(["year", "month"])["price_peak"].median().rename("month_norm")
df = df.join(norm, on=["year", "month"])
df["rel"] = df["price_peak"] / df["month_norm"]
# One basis for the lead and the interactive sentence: June to August.
jja = df["month"].isin([6, 7, 8])
hw_days = int((df["hw"] & jja).sum())
hw_rel = float(df.loc[df["hw"] & jja, "rel"].median())
summer_rel = float(df.loc[jja & ~df["hw"], "rel"].median())
summer_from, summer_to = int(df.loc[jja, "year"].min()), int(df.loc[jja, "year"].max())

ojs_data(days=df.assign(date=df["date"].dt.strftime("%Y-%m-%d"))[
    ["date", "year", "month", "tmax_de", "price_mean", "price_peak"]])
