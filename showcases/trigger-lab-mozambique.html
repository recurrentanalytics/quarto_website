Design a parametric cyclone trigger over 47 seasons of storm tracks and see when it would have paid, when it would have missed, and why. Basis risk, hands on.

Showcase 2 of 4 · risk finance

A parametric cover pays when a measured hazard crosses a line agreed in advance, not when the damage has been counted. That makes it fast. It also means it can pay when little was lost, or stay silent when a lot was. That gap is basis risk. Draw your own line below.

function slider({min, max, step, value, label, fmt}) {
  const out = html`<output></output>`;
  const input = html`<input type="range" min=${min} max=${max} step=${step} value=${value}>`;
  input.setAttribute("aria-label", label);
  const el = html`<label class="tl-ctl"><span class="tl-ctl-head"><span>${label}</span>${out}</span>${input}</label>`;
  const update = () => { el.value = +input.value; out.innerHTML = fmt(+input.value); };
  input.addEventListener("input", update);   // runs before the event bubbles up to the label
  update();
  return el;
}

function choice({options, value, label}) {
  const sel = html`<select>${options.map(([v, t]) => html`<option value=${v}>${t}</option>`)}</select>`;
  sel.value = String(value);
  sel.setAttribute("aria-label", label);
  const el = html`<label class="tl-ctl"><span class="tl-ctl-head"><span>${label}</span></span>${sel}</label>`;
  const update = () => { el.value = options.find(([v]) => String(v) === sel.value)[0]; };
  sel.addEventListener("input", update);
  update();
  return el;
}

// Is a track point inside the zone? Same method as prepare.py: great circle to a city; for
// Mozambique 0 inside the outline, else the distance to the nearest boundary segment in a
// local projection centred on the point.
inZone = {
  if (city) return (lon, lat) => d3.geoDistance([lon, lat], [city.lon, city.lat]) * 6371.0088 <= radius;
  const ring = mozFeature.geometry.coordinates[0], k = Math.PI / 180 * 6371.0088;
  return (lon, lat) => {
    if (d3.geoContains(mozFeature, [lon, lat])) return true;
    const c = Math.cos(lat * Math.PI / 180);
    let best = Infinity;
    for (let i = 0; i < ring.length - 1; i++) {
      const ux = (ring[i][0] - lon) * c * k, uy = (ring[i][1] - lat) * k;
      const dx = (ring[i + 1][0] - ring[i][0]) * c * k, dy = (ring[i + 1][1] - ring[i][1]) * k;
      const t = Math.max(0, Math.min(1, -(ux * dx + uy * dy) / (dx * dx + dy * dy || 1)));
      best = Math.min(best, Math.hypot(ux + t * dx, uy + t * dy));
    }
    return best <= radius;
  };
}

How it works

  • Storms. Every storm since the 1979/80 season with a US-agency (JTWC) track in IBTrACS whose centre came within 500 km of Mozambique: The whole track counts, weak and extratropical stages included. JTWC fixes are 6-hourly (3-hourly in IBTrACS); positions and winds are interpolated to hourly, gaps over 6 hours are not bridged. Mozambique is the 1:50m mainland outline, without small islands.
  • The trigger. A season pays if at least one storm, while its centre is inside your zone, reaches your wind threshold. One payout per season, all or nothing.
  • Disasters. A season counts as a disaster when Mozambique’s disaster management institute (INGD) lists a named storm in it. Earlier seasons are marked “no open record”: no season-by-season record is used here, which does not mean nothing happened.
  • Seasons, not years. Cyclones here come mostly between November and April, so a season spans two calendar years. IBTrACS counts a southern season from July to June.

What this does not show

  • Wind is the storm’s peak, not the wind on the ground. The maximum sustained wind is “the highest one-minute average wind … associated with that weather system” (NHC glossary), wherever it blows in the storm. A cover that measures wind at the site, or modelled losses, behaves differently.
  • Rain and floods. Damage also comes from rain, rivers and storm surge, which a wind trigger does not see. Idai (2019) brought more than 200 mm of rain in 24 hours; rivers overflowed and about 3,000 km² of land was flooded (Government of Mozambique and partners, Post-Disaster Needs Assessment, 2019).
  • Recent tracks are provisional. For the US best tracks are not final yet and may change.
  • The missing record is part of the risk. Before no open record found for this page says which seasons cyclones hurt. Mozambique’s national disaster inventory for 1979–2012 is open on HDX, but only as totals by year or by hazard, not cyclone disasters by season (UNDRR DesInventar via HDX, CC BY; not used here). Without such a record a trigger cannot be tested against the losses it is meant to cover. That gap is basis risk too.
  • Older storm records are thinner.
  • seasons is a small sample for judging a trigger. Real programmes calibrate on long modelled event sets as well as history; some trigger on modelled losses rather than wind (CCRIF, 2015).

This is an educational tool. It reproduces no real insurance product and uses only open data.
